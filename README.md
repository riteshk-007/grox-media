First, run the development server:

```bash

# or
yarn dev
# or
pnpm dev
# or
```

## Privacy and personal data (DPDP Act)

This site collects personal data through its enquiry forms and, with consent,
through analytics. Read [docs/DPDP-compliance.md](docs/DPDP-compliance.md)
before changing a form, adding a tracking script, or answering a privacy
request. The facts the policy depends on live in `src/lib/privacy.ts`.

**If personal data may have been exposed (breach):**

1. **Contain it** — change the SMTP and mailbox passwords and remove the cause.
2. **Record it** — what happened, when found, which data, how many people.
3. **Inform** the affected people and the Data Protection Board of India as the
   DPDP Act and Rules require (check the current Rules for content and
   deadlines first).
4. **Fix it** and update `docs/DPDP-compliance.md`.

Full steps, including who to contact, are in section 6 of that document.
